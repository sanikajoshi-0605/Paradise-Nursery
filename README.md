# Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is an online plant shop application that allows users to browse and purchase houseplants through an interactive shopping cart interface.

The application provides a collection of plants organized into different categories. Users can view plant information, add plants to the shopping cart, update quantities, remove items, and view the total cost of their cart.

## Features

- Browse different categories of houseplants
- View plant images, names, descriptions, and prices
- Add plants to the shopping cart
- Update plant quantities
- Remove plants from the shopping cart
- Dynamically calculate the total cart amount
- Display the number of items in the cart
- Continue shopping from the cart page
- Checkout option with a "Coming Soon" message

## Technologies Used

- JavaScript
- HTML
- CSS
